Solmere is an original coastal crime-game prototype set across Marina Quarter and East Promenade. Play as Nia Vale, drive through traffic, evade the Harbor Patrol, and pursue the Glassline Run toward Pier 9. The current build includes staged on-foot scenes, a minimap, and a contextual vehicle prompt.

## Run it

```sh
node serve.ts
```
